## HAL

Idioma de descrição da interface (IDL) para especificar a interface entre uma HAL e seus usuários. O HIDL permite especificar tipos e chamadas de método, coletados em interfaces e pacotes do Google Cloud. Mais amplamente, HIDL é um sistema de comunicação entre bases de código que podem ser compiladas de forma independente.

O HIDL é usado para comunicação entre processos (IPC).
